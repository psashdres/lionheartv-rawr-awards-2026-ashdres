# AshDres RAWR Awards Voting Page — Dark Theme

This static website uses a black/dark background with blue and orange accents and heart emojis, inspired by the reference FMA voting page.

## Files
- `index.html` — page content and official links for the five categories
- `style.css` — responsive dark styling

## Deploy to Vercel
1. Extract this ZIP.
2. Upload `index.html` and `style.css` to the root of a GitHub repository.
3. In Vercel, choose **Add New → Project** and import the repository.
4. No build command is required. Click **Deploy**.

## Notes
All buttons open official LionhearTV category pages. The official polls may show multiple nominees; this page cannot filter the live poll or submit votes automatically. Follow LionhearTV's current voting rules.
